# استانداردهای بصری و سیستم طراحی رابط کاربری سنترا (`docs/DESIGN.md`)

**نگارش:** ۱.۰.۰  
**محصول هدف:** رابط کاربری کلاینت «سنترا کانکت» (Sentra Connect - Desktop & Android)  
**فناوری پیاده‌سازی:** Tauri v2 + TailwindCSS + HTML5 / TypeScript (فونت بومی وزیرمتن)  
**فلسفه طراحی:** ابزارمحور (Utility-First)، مینیمال، دسترسی‌پذیری بالا (WCAG AA)، پرهیز مطلق از کلیشه‌های هوش مصنوعی  

---

## ۱. ساختار و هندسه رابط کاربری (Form Factor & Layout Hierarchy)

کلاینت «سنترا کانکت» بر مبنای یک پنجره عمودی جمع‌وجور (Compact Vertical Widget) با ابعاد استاندارد **۳۸۰ پیکسل عرض در ۶۲۰ پیکسل ارتفاع** طراحی می‌شود تا بدون اشغال فضای دسکتاپ، به راحتی در گوشه صفحه یا در قالب منوبار/تسک‌بار ویندوز و مک قرار گیرد.

```text
+-------------------------------------------------------------+
| [سنترا]                               (⚙) (پلن: Flow+) [X]  | <- هدر بالا
+-------------------------------------------------------------+
|                                                             |
|                    [ دکمه بزرگ اتصال ]                      |
|                      (O) - وضعیت متصل                       | <- کارت اصلی اتصال
|                        127.0.0.1                            |
|                                                             |
+-------------------------------------------------------------+
|   حالت فعال: [ Sentra Auto ▾ ]         پینگ: [ 38 ms ]      | <- انتخاب‌گر حالت
+-------------------------------------------------------------+
|                                                             |
|       ↓ دریافت: 14.2 MB/s            ↑ ارسال: 2.8 MB/s      | <- ترافیک زنده
|       [============== حجم باقیمانده: 980 GB ==============] |
|                                                             |
+-------------------------------------------------------------+
|  [> کنسول دیباگ و لاگ سیستم ]             (✉ پشتیبانی ۲۴/۷) | <- فوتر و کنسول
+-------------------------------------------------------------+
```

## ۲. پالت رنگی استاندارد (Color System & Semantic Tokens)

پالت رنگی سنترا بر پایه تضاد نوری استاندارد، راحتی چشم در استفاده شبانه و تفکیک معنایی وضعیت‌های شبکه پیاده‌سازی شده است:

| شناسه رنگ (Token) | کد هگز (HEX) | کاربرد و مفهوم در رابط کاربری |
| :--- | :--- | :--- |
| **`bg-canvas`** | `#0D1117` | رنگ پس‌زمینه اصلی پنجره (Dark Slate عمیق) |
| **`bg-surface`** | `#161B22` | پس‌زمینه کارت‌ها، پنل‌ها و بخش کنترل اتصال |
| **`border-subtle`**| `#30363D` | خطوط جداکننده مینیمال با وضوح ۱ پیکسل |
| **`status-disconnected`** | `#6E7681` | خاکستری خنثی؛ حالت قطع ارتباط یا آماده به کار |
| **`status-connecting`** | `#D29922` | کهربایی ملایم؛ در حال هندشیک یا تغییر پروتکل |
| **`status-connected`** | `#2EA043` | سبز زمردی آرامش‌بخش؛ اتصال ایمن و تانل بدون نشت |
| **`status-error`** | `#F85149` | قرمز مات هشدار؛ قطع ارتباط، اتمام حجم یا خطای شبکه |
| **`text-primary`** | `#F0F6FC` | متن اصلی فارسی با کنتراست فوق‌العاده بالا |
| **`text-secondary`**| `#8B949E` | برچسب‌ها، متون راهنما و واحدها (MB/s, ms) |
| **`tier-flow`** | `#A371F7` | برچسب شناسه پلن اختصاصی Flow+ (بنفش ملایم) |

## ۳. کلید اصلی اتصال (The Master Connect Button)

کلید اصلی اتصال نقطه کانونی رابط کاربری است و باید برای کاربران سالمند و افراد بدون تجربه فنی کاملاً شهودی باشد:
- **ابعاد:** دایره‌ای با قطر ۱۲۰ پیکسل با پدینگ لمسی بزرگ (`touch-target` بزرگ‌تر از ۴۴ پیکسل).
- **حلقه وضعیت (Status Halo Ring):**
  * **قطع:** حاشیه خاکستری مات با آیکون سپر غیرفعال (`Shield Off`).
  * **در حال اتصال:** پالس ملایم کهربایی (Pulse Animation با فرکانس ۱ ثانیه، بدون پرش‌های تند).
  * **متصل:** حلقه پیوسته سبز زمردی با آیکون سپر محافظت‌شده (`Shield Check`).
  * **خطا:** حاشیه قرمز همراه با لرزش ملایم حسی (Haptic Subtle Shake).

## ۴. نمایشگر بلادرنگ سرعت و سنجه‌های شبکه (Live Telemetry Display)

- **اعداد بدون لرزش (Tabular Figures):**
  * ارقام سرعت دانلود و آپلود باید با ویژگی CSS: `font-variant-numeric: tabular-nums;` نمایش داده شوند تا تغییر پهنای باند در هر ثانیه موجب تغییر اندازه یا پرش کلمات فارسی مجاور نگردد.
- **نمایشگر گرافیکی حجم:** نوار پیشرفت (Progress Bar) با رنگ خاکستری تیره که با نزدیک شدن به انتهای حجم ماهانه (کمتر از ۱۰٪ باقیمانده) به رنگ کهربایی درمی‌آید.

## ۵. انتخاب‌گر حالت‌های ۵ گانه تجاری (Mode Selector Bottom Sheet)

کلیک روی دکمه حالت (مثلاً `Sentra Auto`) یک صفحه کشویی نرم از پایین (Bottom Sheet) باز می‌کند که ۵ حالت را با آیکون‌های معنادار تفکیک می‌کند:

1. **Sentra Auto:** آیکون رعدوبرق سبز (`Zap`) - برچسب: *«انتخاب خودکار سریع‌ترین مسیر بر اساس کیفیت شبکه»*
2. **Sentra Hydra:** آیکون چندمسیره (`GitFork`) - برچسب: *«پروتکل هیبریدی فوق‌سریع با پینگ بهینه»*
3. **Sentra Shadow:** آیکون سپر مخفی (`EyeOff`) - برچسب: *«نفوذناپذیر در برابر فیلترینگ شدید و شرایط اضطراری»*
4. **Sentra Stealth:** آیکون قفل نامرئی (`ShieldAlert`) - برچسب: *«عبور از فایروال‌های سازمانی با شکستن بسته‌ها»*
5. **Sentra Pulse:** آیکون ضربان امواج (`Activity`) - برچسب: *«مخصوص اینترنت‌های دارای افت و پکت‌لاس بالا»*

## ۶. کنسول عیب‌یابی و لاگ تعاملی (Debug Console)

- در پایین‌ترین بخش پنجره، زبانه کوچکی با عنوان «کنسول دیباگ» قرار دارد.
- با کلیک کاربر، پنلی با پس‌زمینه مشکی (`#000000`) و فونت مونو باز می‌شود که ۵۰ خط آخر وقایع Sing-box را به صورت زنده نمایش می‌دهد.
- مجهز به دکمه تک‌کلیکی «کپی لاگ خطا» جهت پیوست خودکار به تیکت پشتیبانی ربات تلگرام بدون نیاز به دسترسی ادمین.

## ۷. استانداردهای تایپوگرافی فارسی و دسترسی‌پذیری (RTL & A11y Standards)

- **فونت سیستم:** خانواده فونت **Vazirmatn** در وزن‌های ۴۰۰ (عادی)، ۵۰۰ (متوسط) و ۷۰۰ (بولد).
- **جهت‌گیری متن:** تمامی بخش‌ها با `direction: rtl` و ترازبندی مناسب عناصر کنترل، آیکون‌ها و متون کمکی.
- **تطابق با استانداردهای WCAG 2.1 AA:** نسبت کنتراست تمامی متون خوانا به پس‌زمینه بالای `4.5:1` است.
- **حالت‌های فوکوس صفحه کلید:** برای کاربرانی که با Tab پیمایش می‌کنند، یک حلقه خط‌چین آبی ملایم با انحنای استاندارد فعال می‌شود.
