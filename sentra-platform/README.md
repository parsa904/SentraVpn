# 🛡 پلتفرم سنترا (Sentra Platform) - راهنمای جامع فاز ۱

پلتفرم **Sentra** یک اکوسیستم ماژولار، پیشرفته و ضدسانسور شبکه است که برای تضمین دسترسی آزاد، پایدار و امن به اینترنت بین‌الملل بدون نیاز به تغییر زیرساخت‌های سرور خارجی طراحی شده است.

---

## 🏗 ساختار پروژه (Monorepo Architecture)

```text
SentraVpn/
├── sentra-core/                    # هسته مرکزی بک‌اند (Rust / Axum / Teloxide / SQLite)
│   ├── src/
│   │   ├── api/                    # کنترلرهای REST API (اعتبارسنجی، تلمتری، سابسکریپشن)
│   │   ├── bot/                    # دیمن ربات تلگرام و هندلرهای پیشرفته ادمین/کاربر
│   │   ├── compiler.rs             # کامپایلر کانفیگ‌های Sing-box و OpenVPN
│   │   ├── anomaly_detector.rs     # ماژول هوشمند پایش ناهنجاری ترافیک و مسدودسازی خودکار
│   │   ├── db.rs                   # لایه دسترسی داده (SQLite با ژورنالینگ پیشرفته WAL)
│   │   └── models.rs               # ساختارهای داده و روابط دیتابیس
├── sentra-client/                  # کلاینت دسکتاپ و اندروید (Tauri v2 + Vite + TailwindCSS)
│   ├── src/                        # رابط کاربری با الهام از طراحی مهندسی Windscribe
│   │   ├── index.html              # داشبورد یکپارچه، مودال‌های مدیریت دستگاه و تنظیمات تب‌بندی
│   │   ├── main.ts                 # کنترلر سمت فرانت‌اند (مدیریت اتصال، رویدادهای زنده، IPC)
│   │   └── styles.css              # استایل‌های تم تیره (#0F172A)، انیمیشن موجی دکمه پاور و فونت وزیرمتن
│   └── src-tauri/                  # باینری نیتیو Tauri v2 و مدیریت تانل Sing-box
└── docs/                           # مستندات فنی و ساختار پروتکل‌ها
```

## 🚀 راهنمای اجرای محلی کل اکوسیستم (Local Development)

### پیش‌نیازها
- **Rust Toolchain:** نسخه 1.80 به بالا (`rustup update`)
- **Node.js & npm:** نسخه 18 یا 20 به بالا
- **Tauri v2 CLI:** (`cargo install tauri-cli --version "^2.0.0"`)

---

### ۱. راه‌اندازی و اجرای هسته سرور (`sentra-core`)

هسته سرور شامل وب‌سرویس REST API و دیمن موازی ربات تلگرام با پایگاه‌داده محلی SQLite است.

1. وارد پوشه پروژه شوید و فایل `.env` را بررسی نمایید:
   ```env
   HOST=127.0.0.1
   PORT=8080
   DATABASE_URL=sqlite://sentra_local.db
   TELOXIDE_TOKEN=your_bot_token_here       # توکن دریافتی از BotFather
   ADMIN_CHAT_ID=123456789                  # شناسه عددی چت ادمین اصلی
   BASE_URL=http://127.0.0.1:8080
   TELOXIDE_PROXY=http://127.0.0.1:10809   # (اختیاری) پروکسی اتصال به تلگرام
   ```

2. اجرای هسته سرور در حالت توسعه:
   ```bash
   cargo run --manifest-path sentra-core/Cargo.toml
   ```
   *نکته: در اولین اجرا، کلیه جداول دیتابیس به همراه نودهای خروجی ۴ حالت اتصال به صورت خودکار با مد WAL ایجاد می‌شوند.*

---

### ۲. راه‌اندازی و اجرای اپلیکیشن کلاینت (`sentra-client`)

کلاینت دسکتاپ سنترا با رابط مدرن و کمینه‌گرای مهندسی‌شده (**الهام‌گرفته از Windscribe**) پیاده‌سازی شده است.

1. نصب وابستگی‌های فرانت‌اند:
   ```bash
   cd sentra-client
   npm install
   ```

2. اجرای پیش‌نمایش رابط کاربری در مرورگر:
   ```bash
   npm run dev
   ```
   *آدرس پیش‌نمایش در مرورگر: `http://localhost:5173`*

3. اجرای کلاینت دسکتاپ با رانتایم نیتیو Tauri v2:
   ```bash
   npm run tauri dev
   ```

4. کدهای سریع تست لوکال در محیط سندباکس:
   - **`12345678`** ➔ اشتراک پایه **Sentra Lite** (۱۰ گیگابایت - سهمیه‌های روزانه ۲G و ۳G)
   - **`88888888`** ➔ اشتراک حرفه‌ای **Sentra Pro** (۱۵۰ گیگابایت - آی‌پی ثابت باز)
   - **`99999999`** ➔ اشتراک نامحدود **Sentra Flow+** (۱ ترابایت - آی‌پی مسکونی اختصاصی)

## 🌟 قابلیت‌های پیاده‌سازی‌شده در فاز ۱

### الف) رابط کاربری کلاینت (`sentra-client`):
- **طراحی مهندسی و مینیمال (Windscribe-style):** تم تیره ارگونومیک (`#0F172A`)، کارتهای عمیق (`#1E293B`) با خطوط حاشیه ظریف `1px solid rgba(255,255,255,0.08)` و تایپوگرافی استاندارد **Vazirmatn** در چینش راست‌به‌چین (**RTL**).
- **مرکز کنترل اتصال:** دکمه دایره‌ای اتصال با انیمیشن موج وضعیت نرم (`Disconnected` -> `Connecting` [موج کهربایی] -> `Connected` [حلقه زمردی]) همراه با سرعت لحظه‌ای دانلود/آپلود و تایمر مونو دقیق.
- **۴ حالت اتصال اختصاصی:**
  1. 🌐 **وب‌گردی (Web Browsing):** سهمیه روزانه ۲ گیگابایت با نوار پیشرفت درصد مصرف.
  2. ⚡ **دانلود (Download):** سهمیه روزانه ۳ گیگابایت بر بستر Hysteria 2.
  3. 🎮 **گیمینگ (Gaming):** برچسب به‌زودی (UDP بهینه‌شده).
  4. 🔒 **آی‌پی ثابت مسکونی (Static IP):** آیکون قفل برای کاربران رایگان و فعال برای Pro/Flow+.
- **مدیریت هوشمند خطای تکمیل دستگاه‌ها (`MAX_DEVICES_REACHED`):**
  نمایش مودال ۳ دستگاه متصل همراه با دکمه **«حذف و جایگزینی با این دستگاه»** جهت اتصال مستقیم بدون نیاز به مراجعه به تلگرام.
- **پنجره تنظیمات تب‌بندی‌شده:**
  - تب تنظیمات اتصال (Split Tunneling دامنه‌های `.ir`، درایور TUN Mode، Kill-Switch و تست سندباکس).
  - تب لاگ زنده هسته با دکمه **«📋 کپی لاگ‌ها»** با یک کلیک.

---

### ب) پنل مدیریت ادمین در ربات تلگرام (`sentra-core`):
ادمین با ارسال `/admin` یا کلیک روی دکمه **«🛠 پنل مدیریت»** به داشبورد شیشه‌ای دسترسی دارد:
1. **📊 آمار لحظه‌ای سیستم:** گزارش زنده تعداد کل کاربران، مشترکین ویژه Pro/Flow+، کاربران مسدودشده، نشست‌های فعال و حجم ترافیک مصرفی ۲۴ ساعت گذشته.
2. **🔍 جستجو و کارت جامع کاربر (`/user <id>`):** مشاهده مشخصات، پلن، انقضا، مصرف امروز وب‌گردی/دانلود و لیست دستگاه‌ها همراه با دکمه‌های شیشه‌ای:
   - `[➕ ارتقا به Pro (۳۰ روزه)]` و `[➕ ارتقا به Flow+ (۳۰ روزه)]`
   - `[🔄 ریست حجم روزانه کاربر]`
   - `[📱 پاکسازی دستگاه‌های کاربر]`
   - `[🚫 مسدود کردن / ✅ رفع مسدودیت]`
3. **📢 پیام همگانی (Broadcast):** ارسال پیام متنی یا تصویری (`/broadcast <متن>`) به تمام کاربران دیتابیس با نرخ ارسال ایمن ۳۵ میلی‌ثانیه برای پیشگیری از لیمیت تلگرام و ارائه گزارش نهایی.
4. **🧾 بررسی رسیدهای پرداخت دستی:** ارسال خودکار عکس فیش کاربر به ادمین همراه با دکمه‌های `[✅ تایید پرداخت و فعال‌سازی ۳۰ روزه]` و `[❌ رد رسید]` که بلافاصله به کاربر اطلاع داده و اشتراکش را فعال می‌سازد.
