# راهنمای جامع کلاینت دسکتاپ سنترا کانکت (`Sentra Connect Desktop Client`)

**Sentra Connect** نرم‌افزار سبک، مدرن، ضدسانسور و الهام‌گرفته از Windscribe است که بر پایه **Rust و Tauri v2** پیاده‌سازی شده است. این کلاینت با ایجاد یک کارت شبکه مجازی (TUN Interface) و کنترل مستقیم هسته شبکه **Sing-box v1.10+**، ترافیک سیستم‌عامل را بدون نشت DNS و با قابلیت تفکیک سایت‌های ایرانی (Split Tunneling) محافظت و هدایت می‌کند.

---

## ۱. ساختار ماژولار و پشته فناوری

پروژه به صورت دو لایه کاملاً مجزا و ماژولار تفکیک شده است:

```text
sentra-client/
├── package.json                   # پیکربندی اسکریپت‌ها و وابستگی‌های Vite و Tauri API
├── index.html                     # رابط کاربری با طراحی عمودی (380x640)، سازگار با RTL و فارسی
├── src/
│   ├── main.ts                    # کنترلر تعاملی TypeScript، شنونده رویدادهای زنده Tauri و وضعیت UI
│   └── styles.css                 # پالت رنگی تیره (Dark Slate)، استایل کلید اصلی و ارقام Tabular
├── src-tauri/                     # بک‌اند بومی Rust مبتنی بر Tauri v2
│   ├── Cargo.toml                 # وابستگی‌های Rust (tauri, tokio, reqwest, serde, thiserror, ...)
│   ├── tauri.conf.json            # تنظیمات پنجره (380x640)، مجوزها و تعریف Sidecar هسته شبکه
│   ├── capabilities/              # مجوزهای امنیتی استاندارد Tauri v2 (default.json)
│   ├── binaries/                  # محل قرارگیری باینری هسته شبکه (External Binary / Sidecar)
│   ├── icons/                     # آیکون‌های ویندوز (.ico) و تصاویر اپلیکیشن
│   └── src/
│       ├── lib.rs                 # نقطه ورود Tauri، مدیریت بسته‌شدن امن و رجیستر دستورات
│       ├── main.rs                # فایل اجرایی دسکتاپ
│       ├── auth.rs                # احراز هویت با کد ۸ رقمی، ذخیره نشست و مدیریت سطوح اشتراک
│       ├── vpn_manager.rs         # دریافت و کامپایل کانفیگ Sing-box، اجرای پروسس و پاکسازی امن شبکه
│       ├── sandbox.rs             # موتور تست لوپ‌بک بدون هزینه (Zero-cost Sandbox Loopback Mode)
│       ├── telemetry.rs           # استریم زنده خروجی stdout/stderr و ارسال نرخ مصرف به UI
│       ├── error.rs               # خطاهای Strongly-typed با thiserror (قانون Zero-Unwraps)
│       ├── commands.rs            # توابع فرامین IPC قابل فراخوانی از فرانت‌اند
│       └── state.rs               # ساختار داده وضعیت کلاینت و سنجه‌های بلادرنگ شبکه
└── README.md                      # همین مستند راهنما
```

## ۲. دستورات نصب پیش‌نیازها و راه‌اندازی (npm & cargo)

### الف) پیش‌نیازهای سیستمی
- نصب **Node.js** (نسخه ۱۸ به بالا) و **npm**
- نصب کامپایلر **Rust** و ابزار **Cargo** (نسخه 1.80 به بالا)
- روی ویندوز: ابزارهای Visual Studio C++ Build Tools یا زنجیره ابزار GNU

### ب) نصب وابستگی‌های فرانت‌اند
در ریشه پوشه `sentra-client/` دستور زیر را اجرا کنید:

```bash
cd sentra-client
npm install
```

### ج) اجرای برنامه در حالت توسعه (Live Development)
برای اجرای توأم فرانت‌اند و کلاینت دسکتاپ:

```bash
npm run tauri dev
```

یا در صورت ترجیح اجرای مجزا:
1. در یک ترمینال، سرور پیش‌نمایش فرانت‌اند را اجرا کنید:
   ```bash
   npm run dev
   ```
2. در ترمینال دیگر، باینری Rust را اجرا کنید:
   ```bash
   cargo run -p sentra-connect
   ```

### د) ساخت نسخه نهایی (Production Build)
```bash
npm run build
npm run tauri build
```

## ۳. نام‌گذاری و قراردادن فایل باینری خارجی Sing-box (`Sidecar`)

بر اساس استانداردهای فریمورک **Tauri v2**، هر فایل اجرایی جانبی (External Binary) که در کلید `bundle.externalBin` داخل `tauri.conf.json` تعریف می‌شود، باید در پوشه `src-tauri/binaries/` قرار گرفته و نام آن با **Target Triple** پلتفرم مقصد ترکیب شود:

```text
sing-box-<target-triple>[.exe]
```

### جدول نام‌گذاری بر اساس سیستم‌عامل‌ها:

| پلتفرم و معماری | Target Triple | نام دقیق فایل در `src-tauri/binaries/` |
| :--- | :--- | :--- |
| **Windows x64 (MSVC - پیش‌فرض ویندوز)** | `x86_64-pc-windows-msvc` | `sing-box-x86_64-pc-windows-msvc.exe` |
| **Windows x64 (MinGW / GNU)** | `x86_64-pc-windows-gnu` | `sing-box-x86_64-pc-windows-gnu.exe` |
| **Linux x64 (Ubuntu / Debian / Arch)** | `x86_64-unknown-linux-gnu` | `sing-box-x86_64-unknown-linux-gnu` |
| **macOS Apple Silicon (M1/M2/M3)** | `aarch64-apple-darwin` | `sing-box-aarch64-apple-darwin` |
| **macOS Intel x64** | `x86_64-apple-darwin` | `sing-box-x86_64-apple-darwin` |

> **نکته:** برای پیدا کردن Target Triple سیستم خود، کافی است دستور `rustc -vV` را اجرا کرده و مقدار فیلد `host:` را مشاهده فرمایید.

### روش‌های جایگزین برای اجرای باینری:
1. **متغیر محیطی:** قرار دادن مسیر باینری در متغیر محیطی `SING_BOX_PATH` (مثلاً `SING_BOX_PATH=C:\tools\sing-box.exe`).
2. **قرار دادن در PATH سیستم:** اگر `sing-box` در متغیر `PATH` سیستم‌عامل نصب باشد، برنامه به صورت خودکار آن را شناسایی می‌کند.
3. **حالت لوپ‌بک سندباکس (`Sandbox Mode`):** در صورت عدم وجود باینری فیزیکی، برنامه به صورت خودکار و بدون بروز کرش، به حالت شبیه‌ساز سندباکس تغییر وضعیت می‌دهد تا تمام تعاملات کاربر، انیمیشن‌ها و سنجه‌ها قابل بررسی باشند.

## ۴. حالت‌های ۵ گانه اتصال تجاری سنترا (`Connection Modes`)

کلاینت به صورت پیش‌فرض از ۵ حالت تعریف‌شده در سند `docs/PROTOCOL_SPEC.md` پشتیبانی می‌کند:

1. **`Sentra Auto` (پیشنهادی - هوشمند):**
   - گروه `urltest` در Sing-box با پروب سلامت هر ۱۵ ثانیه.
   - مناسب برای کاربران عادی جهت سوییچ خودکار روی سریع‌ترین مسیر در زمان فیلترینگ.
2. **`Sentra Hydra` (فوق‌سریع و مالتی‌پلکس):**
   - استک `VLESS` + `Reality` با شبیه‌سازی اثرانگشت کروم و مالتی‌پلکسینگ `smux`.
3. **`Sentra Shadow` (نفوذناپذیر در اختلال شدید):**
   - استک دو لایه `ShadowTLS v3` به عنوان لایه استتار و `Shadowsocks-2022` به عنوان حامل داده.
4. **`Sentra Stealth` (تکه‌تکه‌سازی پکت و عبور از فایروال):**
   - پروتکل `HTTPUpgrade` به همراه شکستن بسته‌های آغازین TLS (`TLS Fragmentation`).
5. **`Sentra Pulse` (مقاوم در برابر پکت‌لاس شدید):**
   - پروتکل `Hysteria 2` مبتنی بر UDP/QUIC با کنترل ازدحام Brutal و ماسک Salamander.

## ۵. کدهای سریع ورود در محیط سندباکس (Zero-Cost Testing)

جهت تست سریع کلاینت بدون نیاز به ربات تلگرام یا سرور ابری، کدهای زیر در صفحه لاگین به صورت پیش‌فرض قابل استفاده هستند:

- **کد `12345678`:** ورود با اشتراک پایه **`Sentra Lite`** (۱۰ گیگابایت حجم ماهیانه).
- **کد `88888888`:** ورود با اشتراک تجاری **`Sentra Pro`** (۱۵۰ گیگابایت حجم ماهیانه).
- **کد `99999999`:** ورود با اشتراک اختصاصی هوش مصنوعی **`Sentra Flow+`** (۱ ترابایت حجم با خروجی IP مسکونی آمریکا).

## ۶. ارتباط با سرور مرکزی `sentra-core`

کلاینت در هنگام لاگین و اتصال، به API محلی مستقر روی `http://127.0.0.1:8080` متصل می‌شود:
- ورود و تبادل کد ۸ رقمی: `POST /api/v1/auth/code-login`
- دریافت کانفیگ هوشمند: `POST /api/v1/client/config`
- بررسی زنده بودن سرور: `GET /health` (از طریق دکمه «بررسی اتصال به API مرکزی» در پنل تنظیمات).

## ۷. الزامات مهندسی و انضباط کدنویسی (منشور RULES.md)

- **قانون صفر آن‌رپ (`Zero Unwraps`):** هیچ خط کدی در بک‌اند Rust از `.unwrap()` استفاده نمی‌کند و تمام خطاها به کمک `Result` و `Option` به شکل ساختاریافته کنترل می‌شوند.
- **انصراف تمیز و عدم قطع اینترنت هنگام خروج:** به کمک قلاب `on_window_event` در Tauri v2، هنگام بستن پنجره یا زدن کلید قطع اتصال، فرآیند فرزند `sing-box` خاتمه یافته و درایور کارت شبکه مجازی `sentra-tun` آزاد می‌گردد تا دسترسی اینترنت کاربر پس از بسته شدن برنامه مختل نشود.
- **تایپوگرافی اصیل و دسترسی‌پذیری:** اعداد و ارقام سنجه‌های سرعت دارای فرمت `tabular-nums` هستند تا در ثانیه‌شماری لرزش یا پرش متن در رابط کاربری رخ ندهد.
